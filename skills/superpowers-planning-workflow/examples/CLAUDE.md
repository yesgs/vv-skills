# Project Agent Rules

Use the `superpowers-planning-workflow` skill for complex development tasks.

## Required files

For complex tasks, maintain:

```text
.task/task_plan.md
.task/findings.md
.task/progress.md
```

## Workflow

1. Brainstorm before coding.
2. Write or update the plan.
3. Execute one small task at a time.
4. Prefer TDD when practical.
5. Run verification after changes.
6. Update planning files after every meaningful step.
7. Create handoff notes before stopping.
